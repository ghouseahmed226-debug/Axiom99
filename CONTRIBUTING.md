# Contributing to NexusWeb 🎮

Welcome! NexusWeb is maintained by the Swarm 99-agent architecture and the open-source community.

## Development Workflow
1. Fork & branch from `main` or `dev`.
2. Ensure strict TypeScript typing (`npm run typecheck`).
3. Verify linter and tests passing (`npm run lint`, `pytest`).
4. Submit PR with conventional commit messages (`feat:`, `fix:`, `perf:`).
